# 周报

> 每周日晚上花 5 分钟填。**不写"学了什么"，只写"做出了什么"。**
> 目的是给自己看：三个月后回翻，能看出哪段时间在空转。

---

## 周报模板

```markdown
## YYYY 第 N 周（MM/DD–MM/DD）

**投入**：__ 小时（目标 5.5）
**本周产出**：（链接或文件路径，没有就写"无"）
**做成了**：一句话
**卡在哪**：一句话，卡了多久
**下周只做一件事**：
**一句话心情**：
```
