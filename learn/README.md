## `shell.md` 的写法

不要抄 man page。一行命令，后面一句人话：

```
# 找出当前目录下最大的 10 个文件，按大小排
ls -lhS | head -n 10

# 在全部 .py 文件里搜 TODO，并显示行号
grep -rn "TODO" --include="*.py" .
```
