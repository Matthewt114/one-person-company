# 复盘模板（六段式）

> 复制这份文件，改名成 `postmortems/001-简短标题.md`，然后填。
> 标题规则：**具体报错关键词 + 一句人话**。
> 好："`ModuleNotFoundError` 明明装了却说找不到，原因是虚拟环境没激活"
> 差："Python 常见错误总结"

---

## 元信息

| 项 | 内容 |
|---|---|
| 日期 | YYYY-MM-DD |
| 耗时 | 从接手到定位，__ 分钟；到修完，__ 分钟 |
| 环境 | 操作系统 / 语言版本 / 关键依赖版本 |
| 来源 | 自己踩的 / 同学的 / GitHub issue #__ / 社区提问 |
| 关键词 | `报错原文核心词`、`另一个关键词` |

## 一、现象

客户（或我）看到的是什么。**贴原始报错，不要转述。**

```
把报错原文粘在这里
```

做过的操作、什么条件下出现、什么条件下不出现。

## 二、排查思路

按《调试九法》的哪几步走的，为什么这么走。**这一段是给未来的自己看的，写"我一开始以为是 X，后来发现不是"比写"我检查了 X"有价值。**

1. 先确认了……
2. 排除掉……，依据是……
3. 把范围缩小到……，用的是二分法/日志/断点

## 三、根因

真正的问题是什么。**一句话说清**，然后解释为什么它会导致上面的现象。

## 四、修法

改了什么。**必须有 diff**：

```diff
- 原来的代码
+ 改后的代码
```

## 五、验证

不能只写"改完就好了"。按 A-B-A 走：

1. **A（原状态）**：故障稳定复现，复现步骤是……
2. **B（修改后）**：跑了 __ 次 / __ 分钟，故障不再出现
3. **A（恢复原状态）**：故障再次出现 → 证明是这次修改起的作用，不是环境变了

如果做不了 A-B-A，写清为什么做不了，以及你用什么替代证据。
