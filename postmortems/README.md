## 三条规矩

1. **必须有 diff 和验证过程。** 没有这两样，那就不是复盘，是读书笔记。
2. **必须脱敏。** 客户名字、公司名、密钥、内网地址、数据库名，一律替换。
3. **标题必须能被搜到。** 写用户会输入的那个报错词，不要写"浅谈调试方法"。

- 自己踩过的坑（最容易写，也最真实）
