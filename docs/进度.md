## 四、已经踩过的坑（别踩第二次）

| 现象 | 真正原因 | 解法 |
|---|---|---|
| `proxyconnect tcp: ... 7897 ... refused` | Clash 没开 | 先打开 Clash Verge |
| `wsarecv: ... did not properly respond` | 没走代理，直连超时 | 设 `$env:HTTPS_PROXY` 再重试 |
| `git : 无法将"git"项识别为...` | 装完没重开终端 | 关掉 PowerShell 重开 |
| 文件夹搬走后 git 历史没了 | `.git` 是隐藏目录 | 移动仓库整个文件夹一起移，移完 `git status` |
| `git status` 里中文变 `\344\270\200...` | 没设 quotepath | `git config --global core.quotepath false` |
| Markdown 里 `\#`、表格散了 | 从网页/聊天**框选复制**带上了转义 | 点代码块右上角**复制按钮** |
| 解释文字和命令一起粘进终端 | 框选了整段消息 | 只复制代码块 |
| `SyntaxError: invalid character` | 中文引号 `“ ”` | 输入法切英文 |
| `can't open file '...\projects\scripts\...'` | **站错目录**（犯过 3 次） | 先 `pwd`；或直接用绝对路径 |
| `can't open file 'C:\WINDOWS\System32\...'` | **管理员窗口默认落 System32** | 别用管理员窗口 |
| `)print(...)` 挤一行 → `SyntaxError` | 替换整行时吞掉了换行 | 在 `)` 后补回车；VS Code 会标红 |
| `nothing to commit, working tree clean` | 文件**没保存**，git 看不见编辑器的内容 | `Ctrl+S`，看标签页圆点是否消失 |
| 终端刷出 `SUMMARY OF LESS COMMANDS` | 在分页器里误按了 `h` | 连按 `q` 退出 |
| 分页器里粘命令，创建出怪文件名 | 分页器把输入当成搜索/执行 | **先确认回到 `PS >` 提示符再粘** |
| 文件名含 `U+F03A` 之类看不见的字符 | 冒号/引号被符号字体转换成了私有区码点 | 用程序取对象（`$f.Name`），不要手打 |
| `git rm` 报 `has local modifications` | 文件有未提交改动 | 确认要删后加 `-f` |

**四个通用检查：**

```powershell
pwd                  # 我在哪
git status           # 逐行读
git log --oneline    # 做到哪了
where.exe python     # 命令实际跑的是哪个程序
```

**两条保命命令：**

```powershell
git checkout -- 文件名     # 还原某个文件到上次提交（未提交的修改丢弃）
git --no-pager diff        # 看改动，不进分页器
```
