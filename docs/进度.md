## 四、已经踩过的坑（别踩第二次）

| 现象 | 真正原因 | 解法 |
|---|---|---|
| `proxyconnect tcp: ... 7897 ... refused` | Clash 没开 | 先打开 Clash Verge |
| `wsarecv: ... did not properly respond` | 没走代理，直连超时 | 设 `$env:HTTPS_PROXY` 再重试 |
| `git : 无法将"git"项识别为...` | 装完没重开终端 | 关掉 PowerShell 重开 |
| 文件夹搬走后 git 历史没了 | `.git` 是隐藏目录，剪切时被漏掉 | 移动仓库整个文件夹一起移，移完 `git status` |
| `git status` 里中文变 `\344\270\200...` | 没设 quotepath | `git config --global core.quotepath false` |
| Markdown 里出现 `\#`、表格散了 | 从网页/聊天**框选复制**，带上了转义 | 点代码块右上角的**复制按钮** |
| 把解释文字和命令一起粘进终端 | 框选了整段消息 | 只复制代码块里的内容 |
| 报 `SyntaxError: invalid character` | 中文引号 `“ ”` 混进去了 | 输入法切英文 |
| `can't open file '...\projects\scripts\projects\scripts\...'` | **站错目录**（已犯 3 次） | 先 `pwd`；或直接用绝对路径跑 |
| `can't open file 'C:\WINDOWS\System32\projects\...'` | **管理员窗口默认落 System32** | 别用管理员窗口 |
| `)print(...)` 挤在一行 → `SyntaxError` | 替换整行时吞掉了下一行的换行 | 在 `)` 后面补一个回车；VS Code 会当场标红 |
| 脚本能跑但结果不对 | 排序用了文件名而不是时间 | 盯输出，不只看有没有报错 |

**三个通用检查：**

```powershell
where.exe python     # 命令实际跑的是哪个程序
pwd                  # 我现在站在哪
git status           # 逐行读，它永远在说人话
```

**两条保命命令：**

```powershell
git checkout -- 文件名     # 把某个文件还原到上次提交的样子（未提交的修改丢弃）
git diff                   # 提交前看一眼到底改了什么
```
