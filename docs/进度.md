## 五、踩过的坑（按学习价值排）

| 现象 | 真正原因 | 解法 |
|---|---|---|
| 批量操作改到一半，留下半成品 | 边算边改 | **先算全部 → 查冲突 → 再执行**，有冲突整批取消 |
| `a:b` 前缀 → "找不到路径" | Windows 把 `a:` 当**盘符** | 校验非法字符 `\ / : * ? " < > \|` |
| 同一个 `os.rename` 两系统后果不同 | Windows 报错；**Linux/macOS 直接覆盖** | 不靠系统默认行为，自己先检查 |
| `import` 一个脚本，它自己跑起来了 | 代码全在模块顶层 | 函数化 + `if __name__ == "__main__":` |
| `IndentationError: expected an indented block` | `def` 顶格，函数体没缩进 | 函数体比 `def` 多 4 格；VS Code 里 `Tab` / `Shift+Tab` |
| 测试文件全红，`collected 0 items` | **语法错**，不是测试失败 | 先修语法；`collected` 是 0 就说明测试根本没跑 |
| `UnicodeDecodeError: 'gbk' codec` | 中文 Windows 默认 GBK | `open(..., encoding="utf-8")` |
| `FileNotFoundError: D:\客户资料\...` | 路径写死在别人电脑上 | 用 `__file__` 相对脚本定位 |
| `can't open file ...` | 站错目录（犯过 3 次） | 先 `pwd`，或用绝对路径 |
| `nothing to commit` | 文件没保存，git 看不见 | `Ctrl+S`，看标签页圆点 |
| `proxyconnect ... refused` / `schannel ...` | 代理没开 / 节点坏 | 开 Clash / 换节点 |

**四个通用检查**：`pwd` / `git status` / `git log --oneline` / `where.exe 命令名`
**两条保命命令**：`git checkout -- 文件` / `git --no-pager diff`
