## 四、踩过的坑（精选，按学习价值排）

| 现象 | 真正原因 | 解法 |
|---|---|---|
| 批量操作改到一半失败，留下半成品 | 边算边改 | **先算全部 → 查冲突 → 再执行**，有冲突整批取消 |
| `a:b` 前缀导致"找不到路径" | Windows 把 `a:` 当**盘符** | 校验文件名非法字符 `\ / : * ? " < > \|` |
| 相同的 `os.rename` 在两个系统后果不同 | Windows 报错退出；**Linux/macOS 直接覆盖** | 不靠系统默认行为，自己先检查目标是否已存在 |
| `UnicodeDecodeError: 'gbk' codec` | 中文 Windows 默认 GBK | `open(..., encoding="utf-8")` |
| `FileNotFoundError: D:\客户资料\...` | 路径写死在别人电脑上 | 用 `__file__` 相对脚本定位 |
| `ValueError: int('1,200')` | 千分位逗号不是数字 | `int(s.replace(",", ""))` |
| `can't open file ...` | 站错目录（犯过 3 次） | 先 `pwd`，或用绝对路径 |
| `nothing to commit` | 文件没保存，git 看不见 | `Ctrl+S`，看标签页圆点 |
| Markdown 出现 `\#`、表格散架 | 从网页框选复制带转义 | 用代码块的复制按钮 |
| `proxyconnect ... refused` / `schannel ... handshake` | 代理没开 / 节点坏 | 开 Clash / 换节点 |

**四个通用检查**：`pwd` / `git status` / `git log --oneline` / `where.exe 命令名`
**两条保命命令**：`git checkout -- 文件` / `git --no-pager diff`
