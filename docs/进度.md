## 四、已经踩过的坑（别踩第二次）

| 现象 | 真正原因 | 解法 |
|---|---|---|
| `proxyconnect tcp: dial tcp 127.0.0.1:7897 ... refused` | Clash 没开 | 先打开 Clash Verge |
| `wsarecv: ... did not properly respond after a period of time` | 没走代理，直连超时 | 设 `$env:HTTPS_PROXY` 再重试 |
| `git : 无法将"git"项识别为...` | 装完没重开终端 | 关掉 PowerShell 重开 |
| 文件夹搬走后 git 历史没了 | `.git` 是隐藏目录，剪切时被漏掉 | 移仓库整个文件夹一起移，移完 `git status` |
| `git status` 里中文变 `\344\270\200...` | 没设 quotepath | `git config --global core.quotepath false` |
| Markdown 里出现 `\#`、表格散了 | 从网页/聊天窗口**框选复制**，带上了转义和多余空行 | 点代码块右上角的**复制按钮**，或手打 |
| 报 `SyntaxError: invalid character` | 中文引号 `“ ”` 混进去了 | 输入法切英文；出问题先看引号 |

**一条通用检查**：不确定命令实际跑的是哪个程序时——

```powershell
where.exe python
```

输出按 PATH 优先级排列，第一行才是真正执行的那个。
