## 四、已经踩过的坑（别踩第二次）

| 现象 | 真正原因 | 解法 |
|---|---|---|
| `proxyconnect tcp: ... 7897 ... refused` | Clash 没开 | 先打开 Clash Verge |
| `wsarecv: ... did not properly respond` | 没走代理，直连超时 | 设 `$env:HTTPS_PROXY` 再重试 |
| `git : 无法将"git"项识别为...` | 装完没重开终端 | 关掉 PowerShell 重开 |
| 文件夹搬走后 git 历史没了 | `.git` 是隐藏目录，剪切时被漏掉 | 移仓库整个文件夹一起移，移完 `git status` |
| `git status` 里中文变 `\344\270\200...` | 没设 quotepath | `git config --global core.quotepath false` |
| Markdown 里出现 `\#`、表格散了 | 从网页/聊天**框选复制**，带上了转义 | 点代码块右上角的**复制按钮**，或手打 |
| 报 `SyntaxError: invalid character` | 中文引号 `“ ”` 混进去了 | 输入法切英文 |
| `can't open file '...\projects\scripts\projects\scripts\rename.py'` | **站错目录**，相对路径重复 | 先 `pwd` 看自己在哪；`cd` 到对的地方再跑 |
| `nothing added to commit but untracked files present` | 不是报错，是"还没 `git add`" | `git add -A` → `commit` → `push` |

**三个通用检查：**

```powershell
where.exe python          # 命令实际跑的是哪个程序（PATH 优先级）
pwd                       # 我现在站在哪
git status                # 逐行读，它永远在说人话
```
