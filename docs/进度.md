## 四、已经踩过的坑（精选）

| 现象 | 真正原因 | 解法 |
|---|---|---|
| `proxyconnect ... refused` / `schannel ... handshake` | Clash 没开或节点坏 | 开代理 / 换节点 |
| `wsarecv: ... did not properly respond` | 没设 `HTTPS_PROXY` | 设环境变量再重试 |
| `git : 无法将"git"项识别为...` | 装完没重开终端 | 重开 PowerShell |
| 文件夹搬走后历史没了 | `.git` 是隐藏目录 | 整个文件夹一起移，移完 `git status` |
| `\344\270\200...` | 没设 quotepath | `git config --global core.quotepath false` |
| Markdown 里 `\#`、表格散架 | 从网页框选复制带转义 | 用代码块的复制按钮 |
| 命令粘进分页器，生成怪文件 | `less` 把输入当搜索 | 先确认回到 `PS >` 再粘 |
| `can't open file ...` | 站错目录（犯过 3 次） | 先 `pwd`，或用绝对路径 |
| `nothing to commit` | 文件没保存，git 看不见 | `Ctrl+S`，看标签页圆点 |
| **`FileNotFoundError: D:\客户资料\...`** | 路径写死在别人电脑上 | 用 `__file__` 相对脚本 |
| **`UnicodeDecodeError: 'gbk' codec`** | 中文 Windows 默认 GBK | `open(..., encoding="utf-8")` |
| **`ValueError: invalid literal for int(): '1,200'`** | 千分位逗号 | `int(s.replace(",", ""))` |
| 程序能跑但结果不对 | 排序依据 / 逻辑错 | **先验证，再交差**（第 9 法） |

**四个通用检查**：`pwd` / `git status` / `git log --oneline` / `where.exe 命令名`
**两条保命命令**：`git checkout -- 文件` / `git --no-pager diff`
