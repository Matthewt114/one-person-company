rename.py

把一堆乱七八糟的图片，按序号或日期改整齐。

问题

手机连电脑导出一次，200 张照片，名字从 IMG_0001.jpg 排到 IMG_0200.jpg。

这些名字不带任何信息。想找某天拍的那几张，只能一张张点开看；想按时间排序，系统排的是名字，不是日期。

手动改名要一张一张来：右键 → 重命名 → 输入 → 回车。200 张基本等于放弃。

用法

python rename.py "F:\照片" 旅行        # 按序号：旅行-001.jpg
python rename.py "F:\照片" --by-date   # 按日期：2026-10-29-001.jpg
python rename.py "F:\照片" --by-date --dry-run   # 只演练，不改名

先带 --dry-run 跑一遍，看清每一行 旧名 -> 新名，去掉它再真跑。

为什么安全

批量操作最大的坑不是报错，是改了一半。所以它分三步：

  1. 算：把每个文件的新名字全算出来，不碰磁盘
  2. 查：检查目标名是否被占用、是否有两个文件撞名
  3. 改：全部通过了才动手

有任何冲突，一个文件都不改，直接列出问题让你先处理。
