# 项目清单

> 每个做出来的东西，一个子目录，一个 README。
> 判断标准只有一个：**别人能不能照着 README 把它跑起来。**

## 清单

| 项目 | 一句话说明 | 技术栈 | 有真实用户吗 | 状态 |
|---|---|---|---|---|
| scripts/ | 日常小工具（重命名、统计、CSV） | | 自己用 | 进行中 |
