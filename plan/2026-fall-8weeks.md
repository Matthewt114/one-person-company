## 第 1 周（11/02–11/08）· 让脚本不容易坏

**目标**：程序出错时给人一句人话，而不是甩一堆 traceback。

**任务**
- [x] 读自己现在的 `rename.py`，找出三个"可能炸"的地方（目录不存在、文件名重复、权限不足）
- [x] 用 `try / except` 包住它们，出错时打印一句人话 + 退出码 1
- [x] 加一个 `--verbose` 开关：打开时打印每一步在哪
- [x] 改完跑三种情况：正常、目录不存在、目标名已存在

**看什么**：Python 官方教程「错误和异常」<https://docs.python.org/zh-cn/3/tutorial/errors.html>

**产出**：`rename.py` v3，提交记录里能看出"加了异常处理"

**验收**：故意给一个不存在的目录，它该打印人话而不是 traceback。

## 卡住了怎么办（四步，40 分钟内走完）

1. **自己查 20 分钟**：复制报错原文去搜，优先看官方文档和 Stack Overflow。
2. **问 AI，但要求它给提示不给答案**：明确说"只告诉我下一步查什么，不要贴完整代码"。
3. **问人**：带上"我想做什么、实际发生了什么、我试过什么"。
4. **记进 [log/blocked.md](../log/blocked.md)**：一句话写清卡在哪。

---

## 进度落后了怎么办

按这个顺序砍：

1. 砍"看什么"里的链接——书可以下周读，产出不能等
2. 砍任务数量，**保留产出那一行**
3. 砍发布动作，先存草稿
4. 整周跳过，在 `log/` 里写一句"第 N 周跳过，原因是 X"

**绝对不要为补进度熬夜。**
