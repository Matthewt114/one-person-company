## ① 期末前（11/12 – 12/31）

**主线：绩点。**

大一上的绩点会影响保研资格和实习初筛。这 7 周不是"学更多"，是"别把绩点搞砸"。

### 每周做什么（1–2 小时）

- 跑一次 `python -m pytest projects/scripts -v`，确认 10 个还绿
- 有真实想写的复盘就写（没有不写，别凑）
- 每月看一眼知乎那篇的数据

### 明确不做

- ❌ 不开新项目
- ❌ 不学新框架、不报课
- ❌ 不为了"保持节奏"硬写东西

> 空着 7 周不丢人。**这 7 周的任务是按计划空着。**
> 这是提前完成换来的奖励，不是懈怠。

停。什么都不做。

## ③ 寒假（1 月中 – 2 月底，约 5 周）

**目标：能从零看懂一个陌生项目的主流程。**

### 产出（可验证）

- **2 篇读码笔记**，放在 `learn/`
- 每篇回答四个问题：解决什么问题 / 分几层 / 数据从哪进从哪出 / 最巧妙的一处

### 要读的两个项目

| 顺序 | 项目 | 规模 | 为什么读它 |
|---|---|---|---|
| **第 1 个** | [`astanin/python-tabulate`](https://github.com/astanin/python-tabulate) | 单文件、较大 | 一个文件把表格对齐做到极致。看**算法怎么组织**，以及一个函数如何应付几十种边界 |
| **第 2 个** | [`gleitz/howdoi`](https://github.com/gleitz/howdoi) | 小 | 命令行工具 + 网络请求 + 解析网页，能看**一条完整的链路**：输入 → 请求 → 解析 → 输出 |

**读完一个再开下一个，别同时读。**

### 项目地址

```powershell
git clone https://github.com/astanin/python-tabulate
git clone https://github.com/gleitz/howdoi
```

放在 `F:\一人公司创业项目\` 下，**不要放进仓库**（它们是别人的代码）。

### 怎么读（每个 3–4 小时，分两次）

**第一次（60 分钟）：只看结构，不读实现**

```powershell
git ls-files | Measure-Object -Line     # 有多少文件
```

- 看 `README` 和目录结构
- 找出入口（`__main__`、`cli.py`、`app.py`）
- 画出模块关系（纸上有几个框就行）

**第二次（2–3 小时）：只精读一个文件**

- 选核心模块，逐行读
- 遇到不认识的库函数，查文档或 `help()`
- 写下"这里为什么要这么写"
